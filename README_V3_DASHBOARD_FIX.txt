AI 프로세스 V3 대시보드 복원 수정

변경 파일: user/dashboard.html, shared/finance-refresh.css
변경 사항:
- 투자 데이터가 0건이더라도 투자금/누적 수익/수익률 요약 및 진행 상태 표시
- 투자 미등록 시에도 실시간 수익/그래프/수익 로그/진행 단계 표시
- 기존 회원용 다중 투자 상세 UI, 관리자 화면, Supabase 설정 및 지급 함수는 그대로 유지
- 신규 프로젝트에 투자 데이터가 없다면 값은 0으로 표시 (가짜 데이터 생성하지 않음)
- 예전 첨부 대시보드 HTML은 이전 데이터 모델과 상이하여 직접 덮어쓰지 않음

주의: 실제 Supabase 온라인 접속/회원별 조회는 이 ZIP만으로 검증할 수 없습니다.
